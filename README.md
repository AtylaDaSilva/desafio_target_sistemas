# Respostas

# Como rodar os programas
Já deixei preparado os launchers para o VSCode e PyCharm. Basta executar os programas diretamente pela IDE:

PyCharm => Selecione o caminho do interpretador Python (3.12+), salve e execute o arquivo (Ctrl + F5)

VSCode => Instale a extensão Python Debugger (Se já não tiver instalado) e execute os arquivos utilizando o debugger da extensão.
